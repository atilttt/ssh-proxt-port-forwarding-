# reverse ssh tunnel

Скрипт на bash, который поднимает обратный ssh-туннель через VPS. Создаёт сервис systemd, чтобы туннель запускался вместе с системой и переподключался после обрыва.

Пока в разработке, но рабочая версия уже есть. Пишу заодно чтобы разобраться с bash, ssh и systemd.

Сейчас подключение только по паролю, потом добавлю по ключам. Ну и обработку ошибок ещё надо допилить.

## запуск

Нужны systemd, ssh и sshpass. Для Debian/Ubuntu:

```bash
sudo apt install openssh-client sshpass
```

Запускать от root:

```bash
chmod +x tunnel.sh
sudo ./tunnel.sh <ip_vps> <ssh_port>
```

Дальше скрипт спросит локальный порт, удалённый порт, пользователя и пароль от VPS.

Локальный порт — куда пробрасываем на своей машине.
Удалённый порт — какой открываем на VPS.

Например, локальный `22`, удалённый `2222`:

```text
127.0.0.1:2222 на VPS → 127.0.0.1:22 на твоей машине
```

Пока порт доступен только с самого VPS, снаружи к нему напрямую не подключиться.

На VPS должны быть разрешены вход по паролю и ssh-проброс портов.

## сервис

Посмотреть что происходит:

```bash
sudo systemctl status reverse-tunnel
sudo journalctl -u reverse-tunnel -f
```

Перезапустить:

```bash
sudo systemctl restart reverse-tunnel
```

Выключить и убрать из автозапуска:

```bash
sudo systemctl disable --now reverse-tunnel
```

## что пока надо знать

- Пароль лежит в `/etc/reverse-tunnel/password` обычным текстом, права на файл `600`, владелец root. В репозиторий его не кидаем.
- Повторный запуск скрипта перезапишет настройки сервиса.
- Пока есть проверка через ping. Если VPS на него не отвечает, скрипт остановится, даже если ssh работает.
- Если сервис запустился, а туннеля нет — смотри логи.
